# 使用说明（写给做核查的人，不写给程序员）

这份是操作手册。工具的设计思路、配置字段含义在 [README](../README.md)。

---

## 一、第一次用，装什么

1. **Python** —— https://www.python.org/downloads/ 下载安装，安装时**勾上 "Add Python to PATH"**
2. 装截图用的库，打开 PowerShell 执行一次：
   ```powershell
   pip install pillow
   ```
3. **Pandoc**（可选，用来自动生成 Word）—— https://pandoc.org/installing.html

装完验证一下，三条命令都能出版本号就行：

```powershell
python --version
python -c "import PIL; print(PIL.__version__)"
pandoc --version
```

如果 PowerShell 提示「无法加载脚本，因为在此系统上禁止运行脚本」，执行一次：

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

## 二、准备你的清单

### 公司名单

新建一个 `我的清单.txt`，一行一个公司：

```
某某集团有限公司
某某控股股份有限公司
```

### 网站清单

用现成的就行：

- 首次尽调、要查得全 → `config\sites.gov33.json`（33 个政府和司法网站）
- 债券存续期月度核查 → `config\sites.bond6.json`（6 个常用站）

想加减网站，用记事本打开改就行，照着原有格式加一段：

```json
{
  "id": "34",
  "name": "某某网站",
  "url": "https://example.gov.cn/",
  "manual": true,
  "note": "这站要输验证码"
}
```

`id` 决定顺序，两位数字。

## 三、跑起来

在 `FinDiligence` 文件夹里打开 PowerShell（在地址栏输 `powershell` 回车最快），执行：

```powershell
.\run.ps1 -Sites config\sites.gov33.json -Companies 我的清单.txt
```

然后就是重复这个循环：

1. 脚本打开一个网站，**自动把公司名复制好了**
2. 你在搜索框 `Ctrl+V` → 搜索 → 过验证码 → 点进要截的页面
3. 切回 PowerShell 窗口，**按回车**
4. 脚本自动截图、命名、存好，然后复制下一个公司名

截图那一瞬间 PowerShell 窗口会自己缩下去（免得终端被拍进图里），截完自动弹回来，**别以为它崩了**。

### 按键

| 键 | 什么时候用 |
|---|---|
| `回车` | 页面对了，截 |
| `r` | 截错了、页面没加载好，重截一张 |
| `o` | 页面点乱了，重新打开这个网站的首页 |
| `s` | 这条实在查不到，跳过 |
| `n` | 这站登录态掉了，跳过本站剩下的公司 |
| `q` | 不干了，退出（已截的图都在） |

## 四、分批跑（重要）

**别一次跑几百张。** 建议按网站分批：

```powershell
.\run.ps1 -Sites config\sites.gov33.json -Companies 我的清单.txt -Site 04
```

推荐顺序：先跑不用登录的（百度、政府门户），再跑要登录的（天眼查一类），最后跑验证码最烦的
（裁判文书网、执行信息网）。每跑完一站，去输出文件夹抽查两张图，确认没问题再跑下一站。

**中途可以随时 `Ctrl+C` 退出。** 下次再跑，已经截过的图会自动跳过，从断点接着来：

```
[1/1] 已存在: 某某集团有限公司.jpg
```

想重截某一张，把那个 jpg 删掉再跑就会自动补上；想整站重截，加 `-Overwrite`。

## 五、跑完之后

输出长这样：

```
截图输出_20260721/
└─ 某某集团有限公司/
    └─ 04-中国裁判文书网/
        ├─ 某某集团有限公司.jpg
        ├─ 04-中国裁判文书网.md      ← 清单
        └─ 04-中国裁判文书网.docx    ← Word，直接能用
```

`.docx` 是每截完一家自动生成的。如果当时没装 Pandoc，后面补装了想统一生成：

```powershell
.\export_word.ps1 -Root .\截图输出_20260721 -Force
```

## 六、常见问题

**Q：提示 `run.ps1 不是可运行的程序`**
必须带 `.\` 前缀，而且要在 `FinDiligence` 文件夹里。先 `pwd` 看看当前在哪。

**Q：截出来的图里有我的桌面 / 有另一块屏**
确认用的是本仓库的 `capture_screen.py`。它只截浏览器所在的那一块屏。如果还有问题，
用 `-Python` 确认调用的是装了 Pillow 的那个 Python。

**Q：截出来的字很糊**
把浏览器放到分辨率高的那块屏上截（笔记本自带的高分屏通常比外接 1080p 显示器清晰得多），
或者在网页上按 `Ctrl` + `+` 把页面放大到 125% 再截。

**Q：跑到一半浏览器崩了 / 登录态掉了**
按 `q` 退出，重新登录，再跑一遍同样的命令。已截的自动跳过。

**Q：某个网站搜不到结果**
搜不到也要截图存证（说明查过、无记录）。直接按回车截当前的「无结果」页面即可。

**Q：能不能连回车都不用按，全自动？**
不能，也不建议。见 README 里「为什么不做浏览器自动化」—— 自动化浏览器会触发风控，
截图失败或账号受限的代价远大于省下的时间。
